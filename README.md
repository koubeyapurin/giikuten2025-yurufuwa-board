# ゆるふわやりたいことボード — 技育展2025 書類選考通過

学生エンジニア向けのピッチコンテスト **技育展2025** に、3人チーム「もんげーユナイテッド」で出したプロダクトです。
「やりたいこと」を投稿して、共感してくれた人とつながる、**直接誘うプレッシャーをなくしたやさしい SNS 風アプリ** です。
**実装は森平(koubeyapurin)が担当しました**(UI の構成、カテゴリ管理、投稿の追加・削除)。

## デモ

https://koubeyapurin.github.io/giikuten2025-yurufuwa-board/

データはブラウザ(localStorage)に保存されるので、ほかの人とは共有されません。

## 大会について

株式会社サポーターズが主催する、学生エンジニア向けのピッチコンテスト「技育展2025」に出したプロダクトです。2020年から毎年開かれている大会で、書類審査 → オンライン予選(2025年11月2日)→ 決勝(11月30日、TOKYO NODE HALL)の流れで、テーマは自由です。

- 公式ページ(参加要項): https://geek.supporterz.jp/geekten/2025/information

## 結果

書類選考を通過しました。

## 一言紹介とこだわり

友達を誘うのがちょっと億劫な気持ちを、ふんわり解決します。

友達を直接誘うことへの心理的なハードル(断られる不安、気まずさ)をなくすため、「**ふんわり共有**」「**共感ベースのつながり**」というコミュニケーションの形にしました。やりたいことを置いておくだけで、共感した人から反応が来る、従来の SNS やチャットにはない「やさしい誘い方」が特徴です。

## できること

- ニックネームを決めて、「やりたいこと」を投稿する
- カテゴリ(食べたい・遊びたい・学びたい・旅行したい・その他)で分けて、絞り込んで見る
- ほかの人の投稿に 💖・💪・🤝 の3種類の反応を送る(反応は通知に届く)
- 投稿には寿命があり、時間がたつと消える(ピン留めした投稿は残る)
- 探索・通知・アカウントの画面、テーマ(見た目)の切り替え
- スマホのホーム画面に追加できる(PWA)

## 技術

- HTML / CSS / JavaScript(ライブラリなし)
- 保存は localStorage、PWA(Service Worker・manifest)
- GitHub Pages で公開

## 動かし方

ビルドは不要です。Service Worker を使うので、ファイルを直接開くのではなくローカルでサーバーを立てて開きます。

```bash
python3 -m http.server 8000
# http://localhost:8000/ を開く
```
